Partie

Sous le capot

Labyrinthe : Kruskal modifié pour une symétrie horizontale parfaite, puis suppression des culs-de-sac pour créer des boucles. Chaque clic sur « Nouveau labyrinthe » en génère un différent.

IA Pac-Man : Minimax avec élagage alpha-bêta sur un horizon de 4 coups, avec une fonction d’évaluation (score, distance aux pastilles, danger des fantômes) et des sécurités anti-boucle.

Fantômes : A* (chemin optimal) ou glouton, avec les comportements propres à chaque fantôme.

Projet d’origine en Java 21 / Maven, avec une API Spring Boot, MongoDB, des benchmarks et une CI GitHub Actions.
